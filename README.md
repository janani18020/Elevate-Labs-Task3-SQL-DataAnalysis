# Elevate Labs Task 3 - SQL for Data Analysis

## Objective

The objective of this project is to use SQL queries to extract, analyze, and manipulate structured sales data.

## Dataset

The dataset contains 1,200 sales records and 9 columns:

- Order ID
- Date
- Region
- State
- Category
- Product
- Quantity
- Sales
- Profit

## Tools Used

- SQLite
- Python
- Pandas
- Google Colab
- GitHub

## SQL Queries Performed

1. SELECT
2. WHERE
3. ORDER BY
4. GROUP BY
5. SUM()
6. AVG()
7. JOIN
8. Subquery
9. VIEW
10. INDEX

## Key Analysis

- Technology generated the highest total sales among the categories.
- North America recorded the highest total sales among the regions.
- Technology also generated the highest total profit.
- SQL aggregation and filtering were used to analyze sales performance.
- JOINs, subqueries, views, and indexes were used to demonstrate SQL analysis techniques.

## Deliverables

- `Task3_SQL_Queries.sql` - SQL queries used for the analysis.
- `sales_data.csv` - Dataset used for the project.
- SQL output screenshots - Screenshots showing query results.

## Outcome

This project demonstrates the use of SQL for data manipulation, analysis, aggregation, joining tables, creating views, and optimizing queries with indexes.
